# Contributing

Thanks for helping improve HERscope.

1. Open an issue describing the bug or proposed change.
2. Create a branch named `fix/short-description` or `feature/short-description`.
3. Keep changes focused and avoid unrelated rewrites.
4. Test period dates, journal saving, age guidance, and responsive layout when relevant.
5. Never use or commit real health data, exported records, credentials, or secrets.
6. Submit a pull request with a summary, testing performed, and screenshots for UI changes.

HERscope is an educational prototype, not a medical device or a substitute for professional advice.
